# Notes Keeper App

A lightweight full-stack notes application with authentication, profile management, instant note autosave, editing, deletion, and keyword search.

## Features

- User registration and login with JWT authentication
- Basic profile management
- Create, edit, and delete notes
- Autosave note changes while typing
- Search notes by keyword
- Responsive split-pane UI with a polished neon editorial theme

## Tech Stack

- Front end: React, Vite, JavaScript, CSS
- Back end: Node.js, Express.js
- Database: SQLite
- Authentication: JSON Web Tokens, bcrypt password hashing

## Setup

1. Install dependencies:

   ```bash
   npm install
   ```

2. Start the development servers:

   ```bash
   npm run dev
   ```

3. Open the client in the browser from the Vite URL shown in the terminal.

## Production Build

```bash
npm run build
npm run start
```
